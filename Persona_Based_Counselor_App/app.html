⚙ Gemini API setup (required before you can generate advice) ▸

Your key is kept only in this page's memory and is not saved by this app. It is sent directly from your browser to Google's Gemini API when you click "Get Career Advice." Refreshing the page clears it. Because this is a client-side demo, the key can still be exposed through browser/network inspection — do not treat it as a production-secret mechanism, and never commit a real key to GitHub. See the README for the full security explanation.
